rclone-simon

rclone-simon is a personal backup setup used by one person, Simon Szeto. It runs the open-source tool rclone on Simon's own Windows PC to copy his own files into his own Google Drive.

It requests one Google permission: https://www.googleapis.com/auth/drive.file. With it, rclone can see and change only the files that rclone itself created in Drive. It cannot see any other file in the Drive.

The app is not offered to other people.
